PUBLISH:
1. Create a new PUBLIC GitHub repository: rahul-selvam-official
2. Extract this ZIP on your computer.
3. Upload all extracted files and the assets folder to the repository root.
4. GitHub repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. In Pages, set custom domain to rahulselvamanu.com.
6. At GoDaddy, enter the DNS records GitHub Pages shows for your domain. Do not guess DNS values; follow GitHub's current instructions.
7. After DNS and HTTPS work, verify the domain in Google Search Console and submit sitemap.xml.
